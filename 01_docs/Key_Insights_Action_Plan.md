
# Key Insights & Action Plan

```
본 문서는 전체 분석 결과를 종합하여
플랫폼 매출 변동의 구조적 원인을 정의하고,
해당 문제를 해결하기 위한 실행 가능한 액션 플랜을 도출하는 것을 목적으로 합니다.

분석은 Growth Structure, Growth Drill Down, 
Customer Value Structure, Operational Stability 결과를 통합하여 진행하였으며,

매출 변화가 어떤 KPI 구조에서 발생했는지,
그리고 그 원인이 수요/공급 중 어디에 있는지를 명확히 구분하는 데 초점을 두었습니다.

또한 매출 변동의 원인을 구조적으로 분해하고 검증하는 과정에서
해당 문제를 단일 원인인 "신규 고객 유입 감소"로 수렴시켰습니다.

따라서 해결 방향은
운영 안정성 개선이 아닌 Acquisition Funnel 최적화와 Retention 전략 강화에 있습니다.
```

## Key Insights

```
본 섹션에서는 전체 분석을 통해 도출된 핵심 인사이트를 정리합니다.

매출 급락 구간을 중심으로 카테고리, 지역, 운영 안정성, 고객 구조를 순차적으로 검증하였으며,

그 결과 매출 감소가 특정 영역의 문제가 아닌
플랫폼 전체 수요 감소에서 기인했음을 확인하였습니다.

핵심 인사이트는 다음과 같습니다.

1. 매출 급락은 수요 감소에 의해 발생
2. 플랫폼은 Volume 기반 성장 구조
3. Acquisition 중심 비즈니스 구조
4. 운영 안정성은 매출 감소의 원인이 아님
5. 특정 영역 문제가 아닌 전체 수요 감소

본 분석을 통해 정의된 핵심 문제는 다음과 같습니다.

매출 감소는 특정 상품, 지역, 운영 이슈가 아닌
신규 고객 유입 감소로 인해 발생한 플랫폼 전반의 수요 축소 문제
```


- **매출 급락은 수요 감소에 의해 발생**
	- 2017-11 → 2017-12 매출 급락 구간 분석 결과
	- 카테고리, 지역, 운영 안정성 요인과 직접적인 연관 없음
	- 모든 구조적 요인을 제거한 결과 매출 감소는 신규 고객 감소로 수렴
	- **매출 감소는 공급/운영 문제가 아닌 수요 측 문제**

- **플랫폼은 Volume 기반 성장 구조**
	- Revenue = Active Buyers x Orders x AOV 구조 분해 결과
	- AOV, ARPB는 안정적으로 유지
	- 매출 변동은 Active Buyers 변화에 의해 결정
	- **매출은 Value 증가가 아닌 Volume 확장에 의해 발생**

- **Acquisition 중심 비즈니스 구조**
	- Repeat Rate 안정적
	- Cohort Retention 변화 없음
	- Top 10% / Top 1% 매출 집중도 변화 없음
	- **매출은 고객 가치 상승이 아닌 신규 유입에 의존**

- **운영 안정성은 매출 감소의 원인이 아님**
	- 매출 급락 구간에서 cancel_rate, failed_rate 모두 감소
	- 2018년 전반적으로 거래 안정성 개선
	- **운영 이슈는 매출 감소의 원인이 아님**

- **특정 영역 문제가 아닌 전체 수요 축소**
	- 카테고리: 카테고리 구성 변화 없이 전반적 동반 하락
	- 지역: 특정 지역 집중 현상 없음
	- 고객 구조: 특정 고객군 변화 없음
	- **특정 문제가 아닌 플랫폼 전체 수요 감소**

## Action Plan

```
본 섹션에서는 정의된 문제를 해결하기 위한 실행 전략을 제시합니다.

현재 플랫폼은 acquisition 중심 구조를 가지고 있으며,
매출이 신규 고객 유입에 구조적으로 의존하고 있습니다.

따라서 단기적으로는 유입 감소 원인을 정확히 진단하고,
중장기적으로는 retention 기반 구조로 전환하는 것이 필요합니다.

단계적인 실행 전략은 다음과 같습니다.

1. Acquisition Funnel 진단
2. 신규 고객 전환율 개선
3. Acquisition 의존 구조 완화
4. Early Retention 강화
5. Demand Recovery 전략

본 액션 플랜을 통해 기대되는 효과는 다음과 같습니다.

단기(1 ~ 3개월)
	- 신규 유입 감소 원인 파악
	- 마케팅 효율 개선

중기 (3 ~ 6개월)
	- 전환율 개선 → 매출 회복
	- acquisition 성과 안정화

장기 (6개월 +)
	- retention 기반 구조 전환
	- 매출 변동성 감소
```


- **Acquisition Funnel 진단 (원인 진단)**
	- **신규 고객 유입 감소의 직접 원인 파악**
	- 분석 필요 영역
		- 채널별 유입 변화 (Organic / Paid / Referral)
		- 캠페인 성과 (CTR, CVR, CAC 등)
		- 유입 → 구매 전환율 확인
	- 실행 액션
		- Funnel 분해 분석
		- 채널별 성과 비교 및 비효율 채널 제거
		- 고효율 채널 집중 투자

- **신규 고객 전환율 개선 (전환 개선)**
	- **유입 대비 구매 전환율 저하 가능성 점검**
	- 분석 필요 영역
		- 첫 구매 전환율
		- 장바구니 → 결제 전환율
		- 결제 단계 이탈률
	- 실행 액션
		- 랜딩 페이지 최적화
		- 결제 UX 개선
		- 신규 고객 프로모션 (첫 구매 할인 등)

- **Acquisition 의존 구조 완화 (구조 개선)**
	- **현재 구조: 매출이 신규 고객에게 과도하게 의존**
	- **목표: Repeat Rate 증가 → 매출 안정성 확보**
	- 실행 액션
		- CRM 기반 재구매 유도
		- 이메일 / 푸시 / 리타겟팅 캠페인
		- 멤버십 / 리워드 시스템 도입

- **Early Retention 강화 (유지 강화)**
	- **초기 고객 유지율 개선을 통한 재구매 유도**
	- 실행 액션
		- 첫 구매 후 7일 / 30일 리텐션 캠페인
		- 개인화 추천 시스템
		- 재방문 유도 전략

- **Demand Recovery (수요 회복)**
	- **전체 수요 감소에 대응하기 위한 단기 매출 회복 전략**
	- **단기적인 수요 회복을 통한 매출 반등 트리거 확보**
	- 실행 액션
		- 프로모션 전략
		- 가격/혜택 실험 (A/B Test)
		- 트래픽 재활성화
		- 신규 유입 Boost 전략
