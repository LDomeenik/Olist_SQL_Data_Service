
# Adhoc Analysis

```
본 Adhoc Analysis의 목적은 플랫폼 매출 변동의 구조적 원인을 진단하고,
특히 특정 시점에서 발생한 매출 급락의 근본적인 원인을 데이터 기반으로 설명하는 것입니다.

분석은 Delivered 주문 기준 월별 KPI를 기반으로
플랫폼의 성장 구조, 고객 가치 구조, 그리고 운영 안정성을
단계적으로 검증하는 방식으로 진행되었습니다.

특히 2017년 동안 플랫폼 매출이 빠르게 성장한 이후
2017-11 -> 2017-12 구간에서 매출이 급락하는 현상이 관찰되어 해당 구간을 드릴 다운하였습니다.

본 분석은 해당 매출 변동이 아래 중 어떤 요인에 의해 발생했는지를 확인하는 것을 목표로 합니다.

- 고객 가치 변화
- 신규 고객과 재구매 고객 유입 변화
- 특정 상품 또는 지역 수요 변화
- 운영 안정성 문제

본 Adhoc Analysis는 다음과 같은 핵심 질문을 중심으로 진행되었습니다.

- 플랫폼 매출의 성장 구조는 무엇인가?
- 2017-11 -> 2017-12 매출 급락의 직접적인 원인은 무엇인가?
- 플랫폼 매출 구조는 고객 유지 기반인가 혹은 신규 고객 유입 기반인가?
- 매출 변동이 주문 취소, 미수 등 운영 안정성 문제와 관련되어 있는가?

Adhoc Analysis는 다음 네 개의 분석 단계로 구성됩니다.

1. Growth Structure
	- 월별 매출, 주문 수, 구매자 수, AOV 등의 핵심 KPI 시계열 분석
	- 매출 성장 및 급락 구간 식별
	- 매출 변동율 거래량(order_cnt / active_buyers)과 고객 가치(AOV) 관점에서 분해

2. Growth Drill Down
	- 매출 급락이 발생한 2017-11 -> 2017-12 구간을 중심으로 매출 감소의 직접적인 원인 탐색
	- 카테고리, 지역, 신규 vs 재구매 고객 구조 분석

3. Customer Value Structure
	- 고객 1인당 가치(ARPB), 주문 빈도, 매출 분포 등을 분석하여 플랫폼의 고객 가치 구조 진단
	- 신규 고객 기여도 및 코호트 리텐션 분석을 통해 매출의 구조 확인

4. Operational Stability
	- 주문 취소(cancel), 미수(unavailable) 등의 거래 실패 구조 분석
	- 카테고리 및 지역별 취소 위험 분석을 통해 운영 문제 여부 검증

Adhoc Analysis의 분석 종합 결과는 다음과 같습니다.

전체 분석 결과, 플랫폼 매출 성장은 고객 가치 상승보다는
사용자 수 증가에 따른 거래량 확대에 의해 발생한 구조로 확인되었습니다.

또한 전체 매출의 대부분이 신규 고객에서 발생하며,
코호트 리텐션 또한 매우 낮은 수준으로 나타나
플랫폼 매출 구조는 기존 고객 유지보다는
신규 고객 유입에 크게 의존하는 형태로 해석됩니다.

특히 2017-11 -> 2017-12 매출 급락 구간에서는 AOV나 고객 가치의 급력한 하락이 아니라
신규 고객 유입 규모 감소가 매출 감소의 주요 원인으로 확인되었습니다.

또한 동일 구간에서 취소율과 주문 실패율은 오히려 감소하여
해당 매출 감소가 운영 불안정성 확대에 의해 발생한 것이 아니라
신규 고객 유입 감소의 변화에 의해 발생했을 가능성이 높은 것으로 확인되었습니다.

따라서 본 플랫폼의 매출 변동은 운영 문제보다는 
신규 고객 유입 규모 변화에 크게 영향을 받는 성장 구조로 해석할 수 있습니다.
```

## Growth Structure

```

- 매출 성장/급락 구간 식별
- 매출 변동의 구조적 원인 분석(주문 수, 구매자 수, AOV 기여)
- KPI 간 동행 여부 정량 검증
- 예외 구간 탐지

따라서 데이터 전체 기간과 해당 분석에서 사용한 기간은 다음과 같습니다.

- 전체 기간: 2016-09 ~ 2020-04
- 분석 사용 기간: 2017-01 ~ 2018-08

해당 분석의 종합 결론은 다음과 같습니다.

2017년 거래량 중심 고성장을 이룬 후, 2018년 안정화에 진입

1. 2017년은 거래량 기반의 고성장 구간
2. 2017-11은 구조적 성장을 이룬 월 (이후 세부 원인 확인을 위해 드릴 다운 분석 필요)
3. 2017-12 급락은 거래량 감소가 직접적 원인
4. 2018년은 성장 둔화 및 안정화
5. 매출은 가격이 아닌 거래량 중심
6. Repeat 상승은 확인되나, 상승 이유는 추가 코호트 분석 필요
```


### 월별 KPI 성장 상태


- **Gross Revenue: 2017년 고성장 -> 2018년 성장 둔화 및 안정화**
	- 2017-01 -> 2017-11 동안 약 9배 성장
	- 2017-11 -> 2017-12에 -26.8% 급락
	- 2018-04에 최고점 도달
	- 이후 완만한 하락 후 1,000,000 내외 박스권 형성

- **Order Count: 매출 상승/하락과 동일한 방향**
	- 2017-01 -> 2017-11 동안 약 9.7배 증가
	- 2017-11 -> 2017-12에 -24.36% 감소
	- 2018년에는 6,000 ~ 7,000 수준으로 안정화

- **Active Buyers: 매출 상승/하락과 동일한 방향**
	- 2017-01 -> 2017-11 동안 약 10배 증가
	- 2017-11 -> 2017-12에 -24.12% 감소
	- 2018년에는 6,000 수준으로 유지

- **AOV: 매출 변동의 원인이 아님**
	- 2017년 고성장 구간에서 상승하지 않음
	- 일부 월(2017-09, 2018-03 등)에서만 상승 기여
	- 전반적으로 150 ~ 170 수준 유지

- **Repeat Buyer Rate: 해당 분석만으로는 판단 불가(코호트 분석을 통한 세부 분석이 필요)**
	- 2017년부터 2018년까지 점진적 상승 추세를 보임
	- 단, 시계열 분석만으로는 데이터 누적 효과인지 실제 리텐션 개선인지 판단이 불가능함

## Growth Drill Down

```
해당 분석은 2017-11(매출 상위) -> 2017-12(매출 급락) 구간을 대상으로 
매출 감소의 구조적 원인을 파악하는 것을 목적으로 합니다.

분석은 다음과 같은 단계로 진행하였습니다.

- 카테고리별 매출 기여도 분석
- 신규 vs 재구매 구조 분해
- 지역(city_state)별 성장 구조 분해
  
분석 기준은 다음과 같습니다.

- KPI Source: olist_am.vw_kpi_monthly_core
- 주문 기준: Delivered 주문
- 신규 정의: 고객 첫 구매 월(first_purchase_year_month) 기준
- 기여율 계산: ABS 기반 감소 기여율(contrib_to_total_drop)

분석 구간은 매출 급락이 발생한 다음 두 개월입니다.

- 기준 월(성장 구간): 2017-11
- 비교 월(급락 구간): 2017-12

해당 분석의 종합 결론은 다음과 같습니다.

2017-12 매출 급락은 특정 상품 붕괴나 특정 지역 붕괴가 아니라,
신규 구매자 유입 감소에 따른 거래량 축소가 핵심 원인으로 판단

즉, 매출 감소는 상품 믹스 변화나 지역 재편이 아닌
신규 수요 감소에 기반한 전반적 볼륨 감소

1. 카테고리 분석 결과, 매출 상위 카테고리(Top 10)이 대부분 유지(9/10)되었으며,
   상위 카테고리 전반에서 동반 하락하는 패턴이 나타남
2. 신규 vs 재구매 구조 분해 결과, 신규 매출은 감소(-27.4%)한 반면 재구매 매출은 증가(+5.1%)
   또한 신규 구매자 수는 감소(-24.4%)하며 매출 감소의 대부분을 설명
3. 지역 분석 결과, 매출 상위 도시권(Top 10)이 대부분 유지(8/10)되었고,
   핵심 대도시권이 그대로 유지되며 급락이 특정 도시 붕괴가 아닌 
   도시권 전반에서 동반 하락한 구조
4. 지역 x 신규 교차 검증 결과, 특정 대도시가 신규 매출 감소 기여율에서 
   상대적으로 큰 비중을 차지하였으나, 
   Top 10 지역의 합이 약 40% 수준으로 특정 도시 붕괴로 보기 어려운 구조
```
